## 1. TinyWow se seekha (website model)
- Brand naam chhota aur apna (TinyWow) — keywords brand me nahi, **page title** me: "Free AI Writing, PDF, Image, and other Online Tools - TinyWow".
- Home ke sabse upar **category boxes with counts**: PDF Tools 45+, Image Tools 30+, Video Tools 10+, AI Write 10+, File Tools 15+.

- Matlab: user ko pehle screen par hi poora catalog samajh aa jata hai; category box click → us category ke saare tools.

## 3b. Mendox "Toolbox" app — dusra interface reference (Pushpendra ne 2026-10-23 ko bheja, pasand kiya)
- Play par developer **Mendox** ka app bilkul "Toolbox" naam se hai — sirf **5K+ downloads**, 17 MB, listing title "Toolbox - All Tools One App". Scan 1/3 me bhi "toolbox" khoj par 4–5 apps isi ek naam ke mile (5K / 5M / 1M / 10K) — **Play par naam ki takkar allowed hai, par "Toolbox" akela kabhi apna brand nahi ban sakta**; khojne wala bheed me ghulega. Ye Round-2 shortlist ke #2 option ki kamzori ka jeeta-jagta saboot hai.
- **Interface (Pushpendra ko pasand):** dark theme, sabse upar Search bar, phir ⭐ Favorites section, phir saare tools ek hi scroll par bade rangeen tile-grid me. Koi category-diwar nahi — sab kuch pehle screen se scroll karke mil jata hai.
- **Kamzori jo hamara fayda hai:** uske tools khilona/sensor type hain (Coin Flip, Wheel of Fortune, Compass, Noise Meter, Scoreboard) — PDF/AI/file ka koi asal kaam nahi. Itni saaf UI ke baad bhi sirf 5K downloads = UI akela nahi bechta; asal-kaam ke tools + sahi naam hi asal hathiyaar hain.
- **Hamara sangam (final home roop):** Mendox wala tile-grid hi rakhenge, lekin grid **category sections** me bandha hoga — upar Search + Favorites/Featured, phir "📄 PDF Tools" heading ke neeche uske 12 tiles, phir "🤖 AI Tools" ke 7 tiles, isi tarah Image/Video/Audio/Text/Calc — matlab ek hi scroll me saare 59 tools (TinyWow ki category-soch + Mendox ka grid + Pushpendra ke category-box/footer wala plan teeno ek saath). Footer me All Tools tab bhi rahega (wahi grid, bina section scroll ke seedhi A–Z list + search).
